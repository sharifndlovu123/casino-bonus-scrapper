# Five Lines on AI

AI tools used on this project were Claude Code and the Claude API.

Everything went well until we asked it to design our table, and it wrote raw CSS. We advised Bootstrap for simplicity.

It also originally wrote the page logic directly into `index.html` with JavaScript. I wanted the two separated, so the Python stays as our backend and the frontend is just `index.html`.

## How Long Each Task Took

- Codebase: 1.5 hours
- Web page: 30 minutes
- Written production plan: 1 hour
